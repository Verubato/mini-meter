# MiniMeter

Shows fps and ping values on your UI so you can always see your system performance without having to hover over the Blizzard game menu icon.

Freely drag the text anywhere on your UI.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
